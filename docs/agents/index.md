# Для помічника й розробника

Людині ці сторінки не потрібні: це робочі інструкції для ШІ-помічника (агента)
і довідники для того, хто хоче знати, як Нишпорка влаштована всередині.
Помічник отримує більшість із них разом зі скілами, тож читає їх і без сайту.

Точка входу для помічника —
[`AGENTS.md`](https://github.com/SERGIUSH-UA/nyshporka/blob/main/AGENTS.md).
