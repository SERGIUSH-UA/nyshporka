# Куди копати: архіви, довідники, маршрути доступу

П'ятий файл документа «Куди копати». Відповідає на три питання:
- на якому сайті архів викладає скани й описи і за яким шаблоном адреси;
- які друковані довідники дають позиції;
- яким маршрутом майданчик узагалі віддає сторінку.

Що є в конкретному фонді, каже реєстр опису (`keep-fond`), не цей файл.

## Звідки таблиці й як оновлювати

- Основа — щомісячний «Дайджест оцифрування документів державними архівами» Укрдержархіву на `archives.gov.ua`, випуск за серпень 2026 р.
- Адреси взято з тексту дайджесту. Скорочені посилання розгорнуто 18.09.2026. Працездатність кожної адреси окремо не перевірено.
- Архів, що в місяці нічого не звітував, у випуску відсутній. Це нічого не каже про наявність у нього е-ресурсу.
- Колонка «оцифровано» — приклад того, що архів викладає. Це не повний перелік.

Технічне:
- Playwright: `p.chromium.launch(headless=True, channel="msedge")`, без бандлового Chromium; User-Agent підставляти явно.
- `ctx.request.get()` заслін не проходить, лише `page.goto()`. Файл брати через `expect_download`.
- Публічний ресурс Яндекс-Диска: API `cloud-api.yandex.net/v1/disk/public/resources?public_key=<url>` → `/download`.
- DjVu: `djvutxt` показує текстовий шар, `ddjvu -format=pnm -page=N` рендерить сторінку.
- PDF, який браузер відкриває у вбудованому переглядачі (завантаження не стається, `ctx.request.get` отримує 403): відкрити головну сторінку сайту, далі `fetch('<шлях>')` → `blob` → `FileReader.readAsDataURL` усередині сторінки. Так віддав файл ДАЧО.
- Сайт, що не резолвиться, варто спробувати під новою адресою з таблиць вище: обласні архіви переїжджають на `*.archives.gov.ua` і `*.gov.ua`, а старі домени гаснуть мовчки.
