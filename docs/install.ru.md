# Установить и подключить помощника

Главный путь — без единой команды: три программы в правильном порядке и
один готовый запрос. Занимает 30–40 минут, большая часть времени — скачивание.

!!! note "Почему не чат на сайте"

    В чате на claude.ai или chatgpt.com Нышпорка не работает: чат отвечает
    текстом и не имеет доступа к вашему диску. Нужна **программа-помощник**,
    которая разговаривает так же, как чат, но сама выполняет действия на компьютере и
    спрашивает разрешения перед каждым.

## Что нужно

* Windows 10 или 11, macOS или Linux.
* Около 5 ГБ свободного места: модели чтения и всё нужное для них — 2.5 ГБ.
* Подписка **Claude Pro или Max** — для Claude Desktop
  ([планы](https://claude.com/pricing)). Или подписка ChatGPT — для Codex.
  Сама Нышпорка бесплатна: платите только за помощника.

## Шаг 1. Установить Нышпорку

Нышпорка устанавливается **первой**, помощник — последним (почему — в шаге 3).

=== "Windows"

    1. [:material-download: Скачайте установщик](https://github.com/SERGIUSH-UA/nyshporka/releases/latest/download/nyshporka-setup.exe){ .md-button .md-button--primary }
       и запустите его.
    2. Если Windows пишет **«Система Windows защитила ваш компьютер»** — «Подробнее» →
       «Выполнить в любом случае». Так Windows встречает каждую программу, которую
       ещё мало кто скачивал.
    3. На вопрос «Що ставимо» (что устанавливаем) выберите **«Каталоги + читання
       рукопису й пошук у прочитаному»** (каталоги + чтение рукописи и поиск
       в прочитанном).
    4. В конце оставьте галочку «Запустити Нишпорку» (запустить Нышпорку) — в браузере откроется
       приложение. Это ваш компьютер, а не сайт: без интернета оно тоже работает.

=== "macOS и Linux"

    Откройте «Терминал», вставьте одну строку и нажмите Enter:

    ```sh
    curl -LsSf https://raw.githubusercontent.com/SERGIUSH-UA/nyshporka/main/install/unix.sh | sh
    ```

    Когда скрипт закончит, закройте окно терминала.

## Шаг 2. Git for Windows

Скачайте [Git for Windows](https://git-scm.com/downloads/win) и установите,
везде нажимая «Next». Без него в Claude Desktop не открывается вкладка
Code, а Нышпорке он нужен, чтобы установить модели чтения. На macOS Git
обычно уже есть.

## Шаг 3. Claude Desktop

1. Скачайте приложение:
   [Windows](https://claude.ai/api/desktop/win32/x64/setup/latest/redirect),
   [macOS](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect).
2. Запустите и войдите в свою учётную запись.
3. Нажмите вкладку **Code** вверху по центру.

!!! warning "Если Claude уже стоял на компьютере"

    Закройте его **полностью** — правой кнопкой на значке возле часов →
    «Выйти» (Quit) — и откройте снова. Программа запоминает, где искать
    команды, в момент запуска, поэтому о только что установленной Нышпорке не знает.
    Симптом: помощник пишет, что команда `nysh` не найдена.

## Шаг 4. Открыть рабочую папку

Во вкладке Code, прежде чем что-то писать:

1. Выберите **Local** — помощник будет работать на вашем компьютере.
2. **Select folder** → папка `Документи\Нишпорка` (Документы\Нышпорка). Её создал установщик;
   там будут жить сканы, прочитанное и заметки. Если такой папки нет, ваши
   «Документы» синхронизируются с OneDrive, и Нышпорка положила папку рядом.
   Где именно — покажет приложение: **🐾 Огляд** (обзор) → «Перевірити цю машину» (проверить эту машину).
3. Режим разрешений — **Manual**: помощник будет спрашивать перед каждым действием, и вы
   видите, что именно он делает.

## Шаг 5. Вставить готовый запрос

Скопируйте текст целиком в поле ввода и нажмите Enter:

```text
Прочитай https://raw.githubusercontent.com/SERGIUSH-UA/nyshporka/main/AGENTS.md
и сделай по нему всё, чтобы Нышпорка была готова на этом компьютере: проверь
машину, при необходимости установи движки чтения и модели и положи скилы для всех
проектов. Каждый шаг объясняй мне простыми словами.
Когда всё зелёное — спроси, какую фамилию я ищу и в каких написаниях.
```

Помощник прочитает инструкцию, написанную для него, и, каждый раз спрашивая разрешения:

* проверит машину (`nysh doctor`);
* установит модели чтения (`nysh htr install`, `nysh models get`) — это
  самый долгий шаг, около 2.5 ГБ;
* положит скилы — готовые порядки работы (`nysh skills install --user`);
* спросит, какую фамилию ищем.

Готово, когда помощник говорит, что проверка без красных строк, и спрашивает
фамилию. Дальше — [«Как работать»](start.md).

## Другие помощники

**Codex** (OpenAI, подписка ChatGPT):
[приложение](https://learn.chatgpt.com/docs/quickstart) или
[версия для терминала](https://learn.chatgpt.com/docs/cli). Шаги 1 и 2 те
же; в шаге 4 откройте папку `Документи\Нишпорка`; в запросе вместо
«положи скилы для всех проектов» напишите «положи скилы в папку
`~/.agents/skills`».

**Claude Code в терминале** — достаточно одной строки и запуска:

```powershell
nysh skills install --user   # скіли для всіх проєктів
claude
```

**Другие** — любой помощник, который читает скилы в формате `SKILL.md`
(Agent Skills), в том числе OpenClaw. Положить их в его папку:
`nysh skills install --target <тека>`.

## Если что-то не так { #yakshcho-shchos-ne-tak }

| что вы видите | что делать |
|---|---|
| помощник: «команда `nysh` не найдена» | Полностью закрыть Claude (значок возле часов → Выйти) и открыть снова. В терминале — открыть новое окно; не помогло — перезагрузить компьютер |
| вкладка Code предлагает обновить план | Нужна подписка Claude Pro или Max |
| помощник: «среда движков не готова» | Скажите ему: «установи движки чтения и модели» |
| помощник не видит папку со сканами | Папка лежит вне рабочей папки; помощник должен спросить разрешения взять её на учёт (`nysh roots add`). Файлы никуда не переносятся |
| установщик завершился «код 1» | Смотрите последние строки вывода. Чаще всего — оборванное скачивание, нехватка места или антивирус |
| что-то другое | [Написать автору](https://github.com/SERGIUSH-UA/nyshporka/issues), добавив дословно, что написал помощник |

## Без помощника или с Python

Если Python или `uv` уже есть, пакет ставится с PyPI:

```bash
uv tool install "nyshporka[app,archives,htr]"   # або: pip install "nyshporka[app,archives,htr]"
nysh init                      # створити робочу теку
nysh doctor                    # перевірити машину
nysh serve                     # відкрити застосунок у браузері
nysh htr install               # середовище для моделей читання, разово
nysh models get                # моделі читання, ~225 МБ, разово
```

Однострочный установщик для Windows без Python — в PowerShell:

```powershell
irm https://raw.githubusercontent.com/SERGIUSH-UA/nyshporka/main/install/windows.ps1 -OutFile "$env:TEMP\nysh-install.ps1"
powershell -ExecutionPolicy Bypass -File "$env:TEMP\nysh-install.ps1"
```

??? note "Для опытных: наборы, параметры установщика, где лежит исследование"

    **Наборы.** `nysh init` спрашивает, чем вы будете пользоваться; изменить в любой момент —
    `nysh sections`, без переустановки.

    | набор | что есть |
    |---|---|
    | `catalog` | каталоги, газетир, описи фондов — без моделей чтения, экономит ~2.5 ГБ |
    | `amateur` | + чтение рукописи и просмотр сканов |
    | `researcher` (по умолчанию) | + поиск в прочитанном, учёт, экспорт |
    | `lab` | + разметка строк и дообучение моделей (`nysh train`) |

    **Параметры.** Одинаково для скриптов и `.exe`:

    | что задаём | `windows.ps1` | `unix.sh` | `.exe` |
    |---|---|---|---|
    | набор | `-Preset catalog` | `NYSH_PRESET=catalog` | `/PRESET=catalog` |
    | состав пакета целиком | `-Source 'nyshporka[app,archives]'` | `NYSH_SOURCE=…` | — |
    | конкретная версия | `-Version X.Y.Z` | через `NYSH_SOURCE` | вшита в файл |
    | папка установки | `-Home_ D:\Nysh` | — | `/DIR=D:\Nysh` |
    | без вопросов | — | — | `/VERYSILENT` |
    | без пакета справочников | `-NoCatalog` | `NYSH_NO_CATALOG=1` | — |
    | журнал | — | — | `/LOG=setup.log` |
    | где жить исследованию | `NYSHPORKA_WORKSPACE` | `NYSHPORKA_WORKSPACE` | `NYSHPORKA_WORKSPACE` |

    ⚠ `irm … | iex` для скрипта Windows не работает (файл имеет UTF-8 BOM) —
    сначала `-OutFile`, потом `-File`.

    **Машина разработчика.** Установщик ничего не переставляет: `uv` и собственный
    Python 3.12 ложатся в папку приложения, `pyenv`, `conda` и сборки под CUDA
    остаются как были. Вне своих папок — только дописка в PATH.
    `sh -s -- --dry-run` показывает изменения и ничего не делает,
    `NYSH_NO_MODIFY_PATH=1` не трогает PATH. Перечень изменений ложится в
    `install-trace.txt`.

    **Где лежит исследование.** Рабочая папка (в командах — пространство):

    ```bash
    nysh init D:/Дослідження                      # обрати місце при створенні
    export NYSHPORKA_WORKSPACE=D:/Дослідження     # закріпити для всіх команд
    nysh --workspace D:/Дослідження doctor        # разово
    ```

    Без переменной команды ищут `nyshporka.toml` вверх от текущей папки.
    Куда смотрит приложение сейчас — `nysh doctor`, строка «Робочий простір» (рабочее пространство).

    **Mac с процессором Intel.** Устанавливается как везде; `nysh htr install` берёт
    Python и torch из conda-forge, потому что у PyPI нет для него колёс torch новее
    2.2.2.

    **Видеокарта не нужна.** Без неё страница читается за ~20 с – 1 мин
    (в зависимости от процессора и того, сколько на странице строк), с картой —
    за ~10–15 с. Ускорение картой — отдельным шагом, его
    подскажет `nysh doctor`.
