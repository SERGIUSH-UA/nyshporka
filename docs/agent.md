# Підключити агента

Сторінка для того, хто хоче, щоб з Нишпоркою працював не він сам, а
ШІ-помічник: заводив справи, запускав читання, шукав прізвище й показував
вирізки. Термінальних команд тут немає взагалі, якщо йти головним шляхом.
Усе, що треба, — три програми поставити в правильному порядку й один раз
вставити готовий текст.

## Чому не чат

Нишпорка не працює всередині чату на сайті claude.ai чи chatgpt.com. Чат
відповідає текстом і не має доступу до вашого диска. Нишпорці ж треба, щоб
хтось відкривав теки зі сканами, запускав читання на вашому комп'ютері й
дивився результат. Це вміє **агент** — окрема програма, яка розмовляє з
вами так само, як чат, але при цьому сама виконує дії на вашому комп'ютері й
питає дозволу перед кожною з них.

Агентів кілька. Головний шлях на цій сторінці — **Claude Desktop**
(вкладка Code). Він не потребує термінала. Наприкінці є короткі розділи для
Codex і для тих, хто вже працює з Claude Code у терміналі.

Що зміниться у вашій роботі: ви кажете «ось тека зі сканами, прочитай і
знайди Ковальських», агент робить решту й приносить вирізки з рядками, де
щось знайшлось. Дивитись на вирізку й вирішувати, ваш це рід чи ні, лишається
вам — агент цього рішення не приймає.

## Що потрібно

* Windows 10 або 11. На macOS усе так само, різниця лише в першому кроці.
* Близько 5 ГБ вільного місця: рушії читання важать 2.5 ГБ, решта — програми.
* Підписка Claude Pro або Max — без неї вкладка Code не відкриється.
  Актуальні плани — [claude.com/pricing](https://claude.com/pricing).
  Сама Нишпорка безкоштовна, платите лише за агента.
* 30–40 хвилин. Більшість цього часу — завантаження, поруч сидіти не треба.

## Крок 1. Поставити Нишпорку

Порядок кроків тут важливий: Нишпорка ставиться **першою**, Claude Desktop —
останнім. Чому — у кроці 3.

=== "Windows"

    1. Завантажте
       [інсталятор](https://github.com/SERGIUSH-UA/nyshporka/releases/latest/download/nyshporka-setup.exe)
       і запустіть його.
    2. Якщо Windows пише **«Windows захистив ваш ПК»** — натисніть
       «Докладніше», потім «Виконати в будь-якому разі». Так Windows зустрічає
       кожну програму, яку ще мало хто завантажував.
    3. На питання «Що ставимо» оберіть **«Каталоги + читання рукопису й пошук
       у прочитаному»**. Це і є те, заради чого підключають агента.
    4. Дочекайтесь кінця. Наприкінці лишіть галочку «Запустити Нишпорку».

    Ви побачите: у браузері відкрилась Нишпорка. Це ваш комп'ютер, а не сайт —
    без інтернету вона теж працює.

=== "macOS"

    Відкрийте «Термінал» (Launchpad → «Інші» → «Термінал»), вставте один рядок
    і натисніть Enter:

    ```sh
    curl -LsSf https://raw.githubusercontent.com/SERGIUSH-UA/nyshporka/main/install/unix.sh | sh
    ```

    Коли скрипт скінчить, закрийте вікно термінала. Це єдина команда на всій
    сторінці.

## Крок 2. Git for Windows

Завантажте [Git for Windows](https://git-scm.com/downloads/win) і поставте,
скрізь натискаючи «Next». Нічого міняти в налаштуваннях не треба.

Навіщо: без Git у Claude Desktop не відкривається вкладка Code, а Нишпорці
він потрібен, щоб поставити рушії читання. На macOS Git зазвичай уже є.

## Крок 3. Claude Desktop

1. Завантажте застосунок:
   [Windows](https://claude.ai/api/desktop/win32/x64/setup/latest/redirect),
   [macOS](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect).
   Докладніше про перший запуск —
   [у документації Claude Code](https://code.claude.com/docs/en/desktop-quickstart).
2. Запустіть, увійдіть у свій обліковий запис.
3. Натисніть вкладку **Code** угорі по центру. Якщо вона пропонує оновити
   план — потрібна підписка з переліку вище.

!!! warning "Якщо Claude уже стояв на комп'ютері"

    Закрийте його **повністю** — правою кнопкою на іконці в треї біля
    годинника → «Вийти» (Quit) — і відкрийте знову. Просто закрити вікно
    недостатньо.

    Причина проста: програма запам'ятовує, де шукати команди, у момент
    запуску. Нишпорка щойно додала своє місце в цей список, і Claude, який
    був відкритий раніше, про нього не знає. Симптом виглядає так: агент
    пише, що команду `nysh` не знайдено, хоча Нишпорка стоїть.

## Крок 4. Відкрити теку дослідження

У вкладці Code, перш ніж щось писати:

1. Оберіть **Local** — агент працюватиме на вашому комп'ютері.
2. **Select folder** → тека `Документи\Нишпорка`. Її створив інсталятор;
   у ній житимуть скани, прочитане й нотатки.

    Якщо такої теки в «Документах» немає — ваші «Документи» синхронізуються
    з хмарою (OneDrive), і інсталятор поклав теку поруч із домівкою
    користувача, щоб читання не зависало на мережевих файлах. Де саме — покаже
    сама Нишпорка: екран **🐾 Дослідження** → «Перевірити цю машину», рядок
    «Робочий простір».

3. Режим дозволів (перемикач поруч із кнопкою відправлення) — **Manual**.
   Агент питатиме дозвіл перед кожною командою. На перший раз це правильно:
   ви бачите, що саме він робить.
4. Модель лишіть ту, що обрана типово.

## Крок 5. Вставити готовий запит

Скопіюйте цей текст у поле вводу цілком і натисніть Enter:

```text
Прочитай https://raw.githubusercontent.com/SERGIUSH-UA/nyshporka/main/AGENTS.md
і зроби за ним усе, щоб Нишпорка була готова на цьому комп'ютері: перевір
машину, за потреби постав рушії читання й моделі, поклади скіли для всіх
проєктів і підключи MCP. Кожен крок пояснюй мені простими словами.
Коли все зелене — спитай, яке прізвище я шукаю і в яких написаннях.
```

Що станеться далі. Агент прочитає інструкцію, написану для нього, і зробить
по ній кілька речей, щоразу питаючи дозволу:

* перевірить машину (`nysh doctor`);
* поставить рушії читання й моделі письма (`nysh htr install`,
  `nysh models get`) — це найдовший крок, близько 2.5 ГБ;
* покладе **скіли** — готові порядки роботи: перша сесія, читання справи,
  пошук прізвища, облік переглянутого (`nysh skills install --user`);
* підключить Нишпорку як інструмент (`nysh mcp install`);
* спитає, яке прізвище шукаємо.

Ви побачите: агент повідомляє, що перевірка машини без червоних рядків, і
питає прізвище. Якщо в полі вводу набрати `/`, у списку з'являться
`start-research`, `read-case`, `find-surname` — це і є скіли.

Якщо агент пише «команду `nysh` не знайдено» — поверніться до кроку 3 і
перезапустіть Claude повністю.

## Крок 6. Перша робота

Скани ви приносите самі — Нишпорка не викачує справи з переглядачів, куди
треба входити під своїм обліковим записом. Вимоги до теки зі сканами прості й
жорсткі: одна тека — одна справа, зображення лежать прямо в теці, формати
`jpg`, `png`, `tif`, `webp`; PDF читання поки не бере. Докладніше — у
[«Поставив. Що далі?»](start.md), крок 4.

Далі розмовляйте з агентом звичайною мовою:

* «Ось тека `D:\скани\ДАКО 13-1-1`, заведи її як справу. Це метрична книга,
  1850–1855.»
* «Прочитай цю справу.» Книга на 300 аркушів без відеокарти — це ніч;
  комп'ютер не має заснути.
* «Знайди тут Ковальських і покажи вирізки.»
* «Запиши, що я переглянув аркуші 12–40, нашого там немає.»

Три речі, які варто знати з самого початку:

* **Агент не вирішує, чи це ваш рід.** Він показує кандидата й вирізку;
  вердикт ваш. Якщо агент каже «знайдено», просіть вирізку.
* **«Немає» без числа — не відповідь.** Правильна відповідь звучить як
  «прошукано 180 аркушів із 300, у прочитаному тексті збігів немає». Якщо
  агент каже просто «немає», спитайте, скільки аркушів він перевірив.
* **Цифри з машинного тексту звіряйте зі сканом.** Роки, вік, номери актів
  машина плутає частіше за слова, а виглядає це так само впевнено.

## Якщо у вас Codex

Codex — агент від OpenAI, працює з підпискою ChatGPT. Є застосунок і версія
для термінала: [як почати](https://learn.chatgpt.com/docs/quickstart),
[Codex CLI](https://learn.chatgpt.com/docs/cli).

Кроки 1 і 2 ті самі. У кроці 4 відкрийте в Codex теку `Документи\Нишпорка`.
Запит із кроку 5 теж той самий, з однією поправкою: замість «поклади скіли
для всіх проєктів» напишіть «поклади скіли в теку `~/.agents/skills`» — саме
там Codex їх шукає. Агент виконає це командою `nysh skills install --target`
з цим шляхом.

## Якщо ви вже працюєте з Claude Code у терміналі

Тоді вам потрібні лише два рядки, а третій — запуск:

```powershell
nysh skills install --user   # скіли для всіх проєктів
nysh mcp install             # Нишпорка як інструмент, у поточній теці
claude
```

Після оновлення Нишпорки скіли оновлюються самі при наступному запуску;
`nysh doctor` окремим рядком покаже, якщо вони раптом старші за пакет.

## Інші агенти

Нишпорка працюватиме з будь-яким агентом, який читає скіли у форматі
`SKILL.md` (Agent Skills) — зокрема OpenClaw. Де такий агент шукає скіли,
дивіться в його документації; покласти їх туди можна командою
`nysh skills install --target` з потрібною текою.

## Коли щось не так

| що ви бачите | що робити |
|---|---|
| агент: «команду `nysh` не знайдено» | Повністю закрити Claude (трей → Вийти) і відкрити знову. У терміналі — відкрити нове вікно. |
| вкладка Code пропонує оновити план | Потрібна підписка Claude Pro або Max. |
| агент: «середовище рушіїв не готове» | Рушії ще не поставлено. Скажіть агентові: «постав рушії читання й моделі» (`nysh htr install`, `nysh models get`). |
| агент не бачить теку зі сканами | Тека лежить поза простором. Агент має спитати у вас дозволу взяти її під облік (`nysh roots add`); файли при цьому нікуди не переносяться. |
| щось інше | [Написати авторові](https://github.com/SERGIUSH-UA/nyshporka/issues). Додайте, що написав агент, дослівно. |

## Скільки це коштує

Нишпорка — нічого: програма вільна, облікових записів немає, ваші скани нікуди
не відправляються. Читання рукопису йде на вашому процесорі й теж нічого не
коштує, лише часу: близько двох хвилин на сторінку без відеокарти.

Платите ви за агента — підпискою чи токенами. Найдорожче з того, що він може
робити, — розбирати аркуші на поля (дати, імена, ролі): це його модель читає
кожен скан очима, і на книгу в двісті аркушів іде мільйони токенів. Пошук
прізвища й читання такого не потребують: їх робить Нишпорка на вашій машині.
