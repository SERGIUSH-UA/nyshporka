# Прочитати справу на орендованій машині

Читання впирається в процесор: на звичайному ноутбуці справа на три тисячі
аркушів — це тиждень. На орендованій машині з кількома десятками ядер —
година-дві й один-два долари.

!!! warning "Малу справу везти нікуди не треба"
    Підготовка чужої машини займає близько восьми хвилин незалежно від обсягу.
    Сотню аркушів удома прочитати швидше й безплатно.

## Що потрібно

1. **Плагін оренди** — окремий пакет: `pip install "nyshporka[rent]"`. На PyPI
   він зветься `gpuhire`, а команда — `gpurunner`; це не помилка.
2. **Акаунт у провайдера й кілька доларів на балансі** — наприклад, Vast.ai
   і його ключ API (Account → API Keys).
3. **Моделі читання** на вашому комп'ютері (`nysh models get`) — саме їх
   везуть на орендовану машину.

## Як попросити

Скажіть помічникові: *«прочитай цю справу на орендованій машині»*. Він:

1. попросить ключ провайдера й передасть його плагіну — Нишпорка ключ не
   зберігає й не друкує;
2. **назве вилку ціни до оренди**, наприклад «$0.40–$1.10», і без вашого
   «так» нічого не орендує;
3. запустить читання, а сам захід далі йде без вас: оренда, заливка сканів,
   читання, забір тексту, перевірка, що прочитано кожен аркуш, вимкнення
   машини. Текст лягає туди ж, куди й після звичайного читання.

Кілька справ можна прочитати однією орендою — це дешевше.

## Якщо машини обриваються

Дешеві машини на ринку — часто чиїсь домашні комп'ютери, і вони часом
відвалюються посеред читання. Прочитане від цього не губиться, але час і
гроші — частково так. Два способи:

* **Лише датацентри** — скажіть помічникові *«бери лише датацентри»*
  (`--datacenter-only`). Обривів менше, але й машин у рази менше, тож іноді
  доведеться почекати.
* **Проміжне сховище** — безплатний рівень Cloudflare R2. Скани заливаються
  туди один раз, і нова машина після обриву підхоплює роботу сама, навіть
  коли ваш комп'ютер вимкнено. Знадобиться створити в кабінеті Cloudflare
  бакет і ключ доступу — помічник підкаже, куди натиснути
  (`nysh cloud rent storage`).

## Як бережуться гроші

* **Стеля автозапуску** — типово $2: дорожчий захід без вашого підтвердження
  не стартує.
* **Стелі під час роботи** — гроші й години. На стелі читання зупиняється,
  прочитане забирається, машина вимикається.
* **Машина вимикається завжди** — після успіху, помилки, Ctrl+C.
* **Нічого не читається двічі**: повторний захід дочитує лише решту.
* **Скани перевіряються до оренди** — обірваний файл чи неповна тека
  зупиняють усе до першого цента.

!!! danger "Комп'ютер вимикати не можна, поки йде захід"
    За орендою стежить процес на **вашому** комп'ютері. Закрити вікно можна,
    вимкнути чи приспати машину — ні. Після кожного заходу помічник перевіряє
    `nysh cloud rent status`; якщо він каже **«МАШИНУ НЕ ВДАЛОСЬ ПОГАСИТИ»** —
    вимкніть її в кабінеті провайдера.

## Своя машина { #own-machine }

Якщо є свій сервер із доступом по SSH, оренда не потрібна: помічник
підготує його й читатиме там — скажіть йому адресу машини.

??? note "Команди, якими працює помічник"

    ```sh
    nysh cloud rent login                          # ключ провайдера
    nysh cloud rent storage --account <ID> --bucket <бакет>   # сховище R2, за бажанням
    nysh cloud go D:\скани\моя-справа --datacenter-only        # лише датацентри
    nysh cloud go D:\скани\моя-справа --dry-run    # ціна, нічого не орендує
    nysh cloud go D:\скани\моя-справа              # прочитати
    nysh cloud state                               # як справи й скільки витрачено
    nysh cloud stop                                # згорнути захід
    nysh cloud rent status                         # перевірка після заходу
    nysh cloud hosts add дім ivan@192.0.2.10 --key ~/.ssh/id_ed25519   # своя машина
    nysh cloud prepare дім
    ```

    Порядок із приймачами кожного кроку — у скілі помічника `run-case-remote`.
