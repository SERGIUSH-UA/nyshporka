# Лицензии, подписывание и приватность

## Политика подписывания кода

Подписывается **один артефакт** — установщик для Windows
`nyshporka-<версия>-setup.exe` со [страницы релизов][rel]. Колесо и `sdist` на
PyPI не подписываются Authenticode: там целостность гарантирует сам индекс и
[Trusted Publishing][tp] через OIDC, без долговременных токенов.

**Что подписывается и кем.** Файл собирается исключительно в GitHub Actions
(`.github/workflows/release.yml`, job `windows-setup`), из тега `v*`, после
ворот качества и проверки на приватные данные. Ручной сборки на чьей-то машине в
цепочке нет. Проект ведёт один человек, поэтому роли Author, Reviewer и Approver
совпадают; каждая подпись подтверждается отдельно, вручную.

**Проверка для вас:**

```powershell
(Get-AuthenticodeSignature .\nyshporka-setup.exe).Status   # Valid
```

Рядом с установщиком в релизе лежит `.sha256` — им можно сверить
скачанное независимо от подписи.

> Free code signing provided by [SignPath.io](https://about.signpath.io),
> certificate by [SignPath Foundation](https://signpath.org)

⚠ **На данный момент заявка подана, и выпуски ещё не подписаны.** До тех пор Windows
показывает «Система Windows защитила ваш компьютер» — это ожидаемо для программы, которую ещё мало кто
скачивал. Подпись уберёт надпись «Неизвестный издатель», но само предупреждение
исчезнет лишь тогда, когда накопится репутация: Microsoft отменила мгновенное
доверие к сертификатам, в том числе и EV.

[rel]: https://github.com/SERGIUSH-UA/nyshporka/releases
[tp]: https://docs.pypi.org/trusted-publishers/

## Приватность

Нышпорка — локальное приложение: телеметрии нет, учётных записей нет,
исследование никуда не выгружается, а в сеть приложение ходит лишь тогда,
когда его об этом попросили командой. Полный перечень того, куда и зачем, —
[`PRIVACY.md`](https://github.com/SERGIUSH-UA/nyshporka/blob/main/PRIVACY.md).

## Лицензия

[AGPL-3.0-or-later](https://github.com/SERGIUSH-UA/nyshporka/blob/main/LICENSE).

Копилефт здесь не выбор настроения, а требование дерева зависимостей: `Unidecode` —
базовая зависимость (нормализация имён, `utils/text.py`) — под **GPL-2.0-or-later**.
AGPL-3.0 с ней совместима и строже, а приложение работает через браузер, то есть именно
тот случай, который AGPL и покрывает.

⚠ Пакет `strhub` содержит подмодуль `models/abinet` под некоммерческой лицензией
USTC. Нышпорка использует из него **только PARSeq** (Apache-2.0).

**Веса моделей — отдельно, под [CC BY-SA 4.0](https://github.com/SERGIUSH-UA/nyshporka/blob/main/LICENSE-MODELS.md).** В пакете их
нет, они приходят отдельным релизом, а AGPL на бинарных весах не имеет
определённого «соответствующего исходного кода» — то есть ничего бы не защитила, зато
отпугивала бы тех, кто хочет использовать их честно. Условия те же по духу: свободно,
в том числе коммерчески, с атрибуцией, а дообученные веса остаются открытыми.
