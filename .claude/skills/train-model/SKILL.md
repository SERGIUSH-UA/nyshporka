# Дотренувати Писаря: корпус → трен → holdout → бойова

**Вхід** — набори з мітками (`nysh train sets`: ручні `ok` і злиття без `low`)
і хоча б один набір із роллю `holdout` з ІНШОЇ справи того самого жанру.
**Вихід** — ваги в `data/spotter/models/` з карткою, `PRODUCTION.json`
називає їх бойовими, і `nysh read` бере їх.

🔴 Три речі, які не обговорюються: план перед стартом (години, карта, ціна,
хто платить); епоху обирає holdout, не val; нуль без знаменника — не
результат (скільки рядків, скільки назв, які набори).

| | | приймач |
|---|---|---|
| **0** | що є | `nysh train doctor`, `nysh train sets` — holdout є, кропи на місці |
| **1** | план корпусу | `nysh train plan` — `rep` звірено, частки не сходинка |
| **2** | корпус | `nysh train build` — tgz, val не порожній |
| **3** | план трену | `nysh train start --dry-run` — години й ціна названі |
| **4** | трен | `--smoke --yes`, потім `--yes`; `status` показує епохи |
| **5** | забір | `nysh train fetch` (ssh, gpurunner) — чекпойнти на місці |
| **6** | епоха | `nysh train eval --models <чинна>` — таблиця з чинною моделлю |
| **7** | бойова | `nysh train promote … --why` — `nysh models list` показує нову |
| **8** | приймач | `nysh read` новою моделлю на сторінці з відомим позитивом |

---

## 0. Що є

```bash
nysh train doctor
nysh train sets
```

Без holdout далі не йти: епоху не буде чим обирати. Holdout — набір з іншої
справи того самого жанру, роль у `set.json` (`"role": "holdout"`), з ручними
мітками `ok`. Набори з мітками, але без кропів на диску, у корпус не ввійдуть
— `train sets` про це попереджає; лікується `nysh train cut` з прогону.

## 1–2. Корпус

```bash
nysh train plan --recipe own
nysh train build --name v1 --recipe own
```

`own` — лише свої набори (мітки ×4, злиття ×1). `domain`/`lean` додають
зовнішні корпуси з `config/train/sources.yaml`; без опису джерела вони
пропускаються з попередженням. 🔴 Дивитись `rep`, не відсоток: частка
перераховується в ціле число копій, і план каже, коли ±0.5 пп змінює його.
`val` порожній — попередження; тоді рання зупинка й `best` сліпі.

## 3–4. Трен

```bash
nysh train start --corpus v1 --smoke --yes     # одна коротка епоха: конвеєр живий?
nysh train start --corpus v1 --dry-run         # план на повний прогін
nysh train start --corpus v1 --yes             # запуск
nysh train status
```

Де рахувати — за прапорцем: нічого → своя карта (середовище рушіїв, `nysh
htr install`); `--host <машина>` → свій сервер по SSH (`nysh cloud hosts`,
`nysh cloud prepare`); `--backend modal|vast|kaggle --gpu …` → gpurunner,
якщо він на шляху. Той самий `params.json` на всі три.

🔴 Стеля часу `wall_limit_h`: раннер сам зупиниться, і план каже, на якій
епосі. Локально на Windows без DDP. Карта на 4 ГіБ — `-p batch=16`.
🔴 vast тарифікує до cancel: після `fetch` — `nysh train stop`.

`run_id` детермінований: повторний `start` з тим самим корпусом і параметрами
підхоплює свій прогін, а не заводить другий рахунок.

## 5–6. Епоха по holdout

```bash
nysh train fetch                         # ssh / gpurunner
nysh train eval --models pysar_cyr_v17   # чинна модель у тій самій таблиці
```

Таблиця: recall власних назв і CER усіх епох + чинної моделі одним прогоном.
Читати так:

- **первинний критерій — recall**: Нишпорка шукає прізвища, а не читає
  текст; коли переможець за recall програє за CER — це відомий розхід, а не
  помилка виміру;
- **micro поруч із macro**: розбіжність між ними означає, що рейтинг
  тримається на малому наборі — вірити micro;
- **⚠ набори з <60 рядків** самостійного висновку не витримують;
- 🔴 **покращення val у лозі трену — не доказ**: три прогони поспіль val
  падав, а recall на holdout не рухався.

Нова модель не краща за чинну на holdout → не просувати. Що далі: мітки
НОВОГО письма того самого жанру, а не перерозподіл часток; три такі ручки
(частка, обсяг злиття, вага домену) уже перевірені й дають нуль.

## 7–8. Бойова

```bash
nysh train promote <прогін> --epoch 9 --as pysar_cyr_v18.pt --why "recall 74→79% на h1+h2 (312 назв), CER 18→17"
nysh models list
nysh read <тека> --limit 5
```

`promote` відмовляє без `select.json` і без `--why`; `--force` — лише
свідомо, і картка це фіксує. Приймач — прочитати новою моделлю сторінку, де
прізвище точно є, і побачити його в тексті.

## Пастки

- **Holdout у трені** = CER 2% там, де чесно 23%. Роль `holdout` виключає
  набір і з ручних міток, і зі злиття.
- **Той самий кроп із двома мітками** (ручна й злиття) — вчить модель на
  суперечності; збірник виключає злиття на рядках із ручною міткою сам.
- **Друковані шапки формуляра** набивають корпус: стеля повторів для друку
  ×3, для руки ×10; друк — текст із чотирьох і більше різних наборів.
- **Кропи зникли** (тека кешу знесена) — мітки лишились, корпус порожній;
  `train sets` каже, які набори без кропів.
- **`.jsonl` у tgz** раннер прочитав би як маніфест — збірник відмовляє.
