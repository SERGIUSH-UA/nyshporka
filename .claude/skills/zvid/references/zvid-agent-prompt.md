# Промпт субагента Зводу

Підставити `{...}` і дати агентові. Один агент — один файл завдання.

---

Ти зводиш рядки рукопису в мітки для навчання моделі. Твоє завдання — ОДИН файл:
`{файл завдання}` ({N} рядків, сторінки {сторінки}).

Пісочниця: `{пісочниця}`. Опис справи — `{пісочниця}/context.md`, прочитай
його першим. Аркуші з пронумерованими рамками — шлях у тексті завдання
(«★ АРКУШІ»). Ціла сторінка — `{пісочниця}/pages/{набір}/<стор>.jpg`.
Дивилка:

    nysh -w "{пісочниця}" train view strip --set {набір} --page <стор> --lines 0-8 --out {тимчасова}/s.png
    nysh -w "{пісочниця}" train view zoom --set {набір} --page <стор> --line <N> --from 0 --to 0.4 --out {тимчасова}/z.png
    nysh -w "{пісочниця}" train view ctx --set {набір} --page <стор> --line <N> --out {тимчасова}/c.png

Тимчасові файли — ТІЛЬКИ в `{тимчасова}`. У пісочниці створюй лише свій
`.answer.json` поруч із файлом завдання.

## Порядок

1. **Шапка завдання до «Рядки:» — цілком.** Там процедура, правила, джерела,
   словник. Вони головніші за все нижче.
2. **Сторінка як документ**: що за акт чи формуляр, хто сторони й урядники, де
   починається і кінчається акт, що за рука. Аркуш із рамками — щоб бачити
   номер кожного рядка.
3. **Рядки зверху вниз.** Процедура `crop-read` — КОЖЕН рядок на його кропі;
   `arbiter` — кроп на кожній власній назві, числі, даті.
4. **Запис порціями**: `{файл завдання без .txt}.answer.json`,
   `{"<id>": {"m": "<мітка>", "c": "high|med|low"}}`, кожні 25 рядків — файл
   цілком тим, що вже зведено. Наприкінці звір кількість і множину id з
   файлом завдання.

## Як читати

- **Мітка — рівно те, що на кропі.** Слова з `ctx` і зі сторінки, які рамка
  відрізала, — для розуміння, у мітку не йдуть. Перше й останнє слово мітки
  видно на самому кропі.
- **Рядок — смужка, не речення.** Обірване слово лишай обірваним, навіть коли
  джерело дає його повністю.
- **Ініціал чи розчерк на полі поза кропом** у мітку не входить.
- **Ширина слова — об'єктивний арбітр**: слово, щільніше за сусідів того ж
  рядка вдвічі, фізично не влазить.
- **Ім'я підписанта** — з писарського повторення поруч, не з розчеркового
  автографа.
- **Голоси бувають правіші за тебе**: рідкісне ім'я не «виправляй» до
  частотного, поки не подивився на збільшенні.
- **Одностайність голосів нічого не гарантує**: моделі помиляються схоже.
- **Людське джерело** (`ВИД:` тощо) — прочитання слів, не межі й не правопис.
  `⚠` — межа рядка сумнівна, дивись першими. Розходиться з кропом — вирішує
  кроп.
- **Правопис** — як у рукописі; умовності (виносні, ъ/ь, скорочення) — з
  `context.md`.
- **Нічого не викидай**: нерозбірливе — найкращий здогад і `low`. Смужка без
  тексту → `"m": ""`.
- **🔴 Маркерів розбіжності НЕ став**: жодних `‹A|B›`, дужок, слешів, `[?]`.
  Обери одне і постав `low`.

**Впевненість — за правилом:**

| що в рядку | стеля |
|---|---|
| кожне слово звірене на кропі | `high` |
| текст певний, окремі літери чи виносні не звірені на збільшенні | `med` |
| власна назва не звірена на збільшенні | `med`, не вище |
| сумнів лише в обірваному слові на краю, кінцевому ъ/ь чи одній виносній | `med` |
| вибір наосліп, нечитабельне без людського тексту | `low` |

Хибний `high` труїть корпус; `low` відсівається і тому мусить бути чесним — але
й не зайвим: `low` викидає рядок із навчання. Перший пакет Зводу поставив `low`
27 рядкам контрольної сторінки з 35, хоча їхній CER був 4,4% — розбіжності лише
на краях рядка й у кінцевому ь.

## Наприкінці поверни

Скільки ключів записано; скільки high/med/low; де джерело розходилось із
кропом (id і як вирішив); що лишилось непевним.
