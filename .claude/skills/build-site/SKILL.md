# Сайт роду з канону

**Вхід** — канон, який проходить `nysh canon check` без помилок. **Вихід** —
тека `<простір>/site/private/html` або `<простір>/site/public/html` зі статикою,
яку можна відкрити в браузері чи викласти на хостинг.

Потрібен MkDocs: `pip install nyshporka[site]` (без нього команда скаже саме це).

---

## Крок 1 — канон цілий

```bash
nysh canon check
```

На помилках збірка відмовиться: сайт із битими зв'язками бреше. Попередження
`maybe_living` — особа без смерті, народжена за останні 100 років, без
`private: true`. У приватній версії її дати й нотатки будуть видні повністю, тож
спитай людину й познач `private: true` (скіл `keep-canon`).

## Крок 2 — яка версія

| версія | для кого | живі |
|---|---|---|
| приватна (`nysh site build`) | сам дослідник, родина за паролем | є, дати до десятиліття, без фото й нотаток |
| відкрита (`nysh site build --public`) | будь-хто в інтернеті | немає зовсім: ні сторінок, ні імен у дереві, ні сканів |

🔴 **Викладати в інтернет — лише відкриту.** Приватна несе повне дерево
(`tree.full.json`) для локального перегляду.

Хто прихований у відкритій версії: `private: true`; без смерті й народжені від
`born_after` (1920); померлі від `died_after` (2000) — у них найближчі живі;
особи без жодного року — за родиною; поіменно `extra_hide`. Пороги й винятки —
`data/site/site.yml`.

## Крок 3 — зібрати й подивитись

```bash
nysh site build --public
nysh site serve --public        # http://127.0.0.1:8765/
```

**Приймач відкритої версії:** команда закінчилась ✅, а не ⛔ «називає
прихованих». Сторож шукає в готовому HTML і пошуковому індексі імена й ID
прихованих; знайшов — HTML видаляється, і перелік витоків названо поіменно.
Витік зазвичай сидить у рукописній сторінці з `overlay/`: виправ текст там, а не
послаблюй пороги.

Попередження `namesakes` — тезки прихованих серед опублікованих: їхні імена
пробою не стали, тож перегляд цих сторінок оком обов'язковий.

## Налаштування: `data/site/site.yml`

Усе необов'язкове: назва й опис, пороги приватності, групи місць для переліку
й мапи (`place_groups` з підрядками адмінподілу), епохи мапи (`eras`), власні
пункти меню (`nav_before`, `nav_after`). Власні сторінки — історії, гілки —
кладуться в `data/site/overlay/` і перекривають згенеровані з тим самим іменем.
Повний перелік полів — у докстрінгу `nyshporka.site.config`.

## Куди викласти

Пакет не деплоїть. Тека `html` — звичайна статика: GitHub Pages, Cloudflare
Pages, Netlify, власний сервер. Приватну версію — лише за авторизацією
(наприклад, Cloudflare Access) або локально.
