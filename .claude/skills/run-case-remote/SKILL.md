# Читання справи на чужій машині

**Вхід** — справа (тека кадрів або шифра з бібліотеки). **Вихід** — текст у
теці прогону, число сторінок із текстом = число кадрів, справа видима в обліку,
машина відпущена, на акаунті нічого не тарифікується.

🔴 **Головне: «хмара» тут не означає «потужніша карта».** Найдорожче в сторінці
рахує процесор — близько трьох чвертей часу йде на геометрію рядків. Тому
єдина причина везти справу кудись — там **більше ядер**. Відеопам'ять не
прискорює нічого, вона лише обмежує, скільки процесів улізе поруч.

Наслідок, який економить найбільше: **малу справу везти нікуди не треба.**
Холодний старт чужої машини коштує близько восьми хвилин незалежно від обсягу —
на сотні кадрів весь захід і буде цими вісьма хвилинами. `nysh read <тека>`.

Шляхів два. Машини немає — **оренда** (розділ А). Машина є — **своя** (розділ Б).

## А. Оренда: одна команда

Оренду дає окремий пакет-плагін; у самій Нишпорці його немає. Що стоїть —
`nysh cloud hosts list` (рядок з `rent` у дужках) і `nysh doctor` (рядок
«Оренда»). Немає — `pip install "nyshporka[rent]"` або `nysh update`.

### А0 — ключ, один раз

```bash
nysh cloud rent login       # ключ питається прихованим запитом
nysh cloud rent status      # ключ, баланс, і що ЗАРАЗ тарифікується
```

🛑 **Ключ дає людина.** Не проси вставити його в чат і не передавай через
`--key`: прапорець лишається в історії оболонки. Нишпорка ключа не зберігає —
він іде бекендові, у просторі дослідження його немає.

### А1 — сухий прогін, який нічого не коштує

```bash
nysh cloud go <справа> --dry-run
```

Робить усе, крім оренди: звіряє кадри, стискає завеликі, складає план, питає
ринок і друкує **вилку** кошторису з рішенням. Читати так:

* **вилка `$низ–$верх`**: низ — прогноз ринку, верх — він же ×2.5 (щільність
  письма невідома до першого читання; ×2 уже не вистачало). **Бюджет заходу =
  верх**, і на ньому захід сам зупиниться;
* **рішення**: верх ≤ стелі автозапуску (типово $2) — захід стартує без
  людини; понад неї — потрібен `--confirm`;
* **«невідомо»** означає, що бекенд цього числа не дав. Не підставляй своє.

🔴 **Відмови до оренди — це робота, а не перешкода.** Битий кадр, тека, що ще
качається, кадрів менше, ніж знає бібліотека, «вже прочитано цією моделлю»:
кожна з них після оренди коштувала б грошей. `--allow-partial` і `--rerun`
існують, але це рішення людини — скажи їй, чому захід відмовив.

🔴 **Письмо мусить бути визначене** (`--script cyrillic|latin`), якщо план каже
«не визначається»: невідповідність рушія письму **не дає збою** — текст
виходить, впевненість не падає. Мішане письмо — `--with latin`.

### А2 — захід

```bash
nysh cloud go <справа>                 # у межах стелі автозапуску
nysh cloud go <справа> --confirm       # 🛑 лише з дозволу людини
```

🛑 **`--confirm` — слово людини, не твоє.** Код виходу 10 означає «захід
дорожчий за стелю автозапуску»: покажи людині вилку й спитай. Підняти стелю
назавжди — теж її рішення: `nysh cloud rent ceiling <сума>`.

Далі захід іде сам: оренда → середовище рушіїв → заливка → читання під наглядом
двох стель (гроші й години) → забір → звірка по диску → один догін малого
хвоста на живій машині → гасіння → `cases build` і `text index`.

Агентові — `--json`: поступ іде рядками, **останній рядок — один об'єкт**
(`verdict`, `pages_done`, `pages_total`, `spent_usd`, `released`, `out_dir`,
`run_id`, `notes`).

| код | вердикт | що робити |
|---|---|---|
| 0 | `ok` | справа прочитана; далі пошук по готовому |
| 2 | `refused` | відмова до оренди — причина в `why` |
| 3 | `failed` | збій; що встигло прочитатись — забрано |
| 4 | `incomplete` | бракує сторінок і після догону; малий хвіст — `nysh read <тека>` вдома |
| 5 | `budget_stop` | стеля грошей; прочитане збережено |
| 6 | `market_empty` | ринок порожній: пізніше або вища `--max-price` |
| 7 | `deadline` | стеля годин; прочитане збережено |
| 8 | `no_credit` | на рахунку менше за верх вилки — поповнює людина |
| 9 | — | 🔴 **машину НЕ погашено** — див. нижче |
| 10 | `needs_confirm` | потрібен дозвіл людини |
| 130 | `cancelled` | перервано; прочитане забрано, машину погашено |

🔴 **Після `budget_stop`, `deadline` чи `incomplete` правильна дія — та сама
команда ще раз.** Уже прочитане їде на нову машину, рушій його пропускає, а на
ринок іде кошторис лише на решту. Нічого не читається й не оплачується двічі.

🔴 **Після обриву термінала — теж та сама команда.** Робота живе на машині
відчеплено; повторний `go` підхоплює **свій** захід разом зі стелями й другої
машини не бере. Кілька `go` різних справ з різних терміналів — штатно.

⚠ Стелі стереже сам процес `go`. Поки термінал закритий, їх не стереже ніхто
з нашого боку — лишається страховка бекенда (бокс знищує себе сам через
`max_hours + 1` годину). Тому захід, чий термінал обірвало, підхоплюй одразу.

### А3 — приймач грошей, після КОЖНОГО заходу

```bash
nysh cloud rent status        # код 3 — щось тарифікується поза заходами простору
nysh cloud state --all        # 🔴 поруч із заходом, який ще тримає машину
```

🔴 **«Невідомо» — не «нічого».** Якщо `rent status` каже, що спитати провайдера
не вдалось, повтори; не звітуй людині «все погашено» з такої відповіді.

🔴 **Код 9 / «МАШИНУ НЕ ВДАЛОСЬ ПОГАСИТИ»** — єдиний випадок, коли гроші горять
без нагляду. Одразу: `nysh cloud stop <захід> --force`, знову `rent status`, і
якщо машина лишилась — скажи людині погасити її в кабінеті провайдера. Не
продовжуй іншу роботу, доки це не закрито.

## Б. Своя машина: дрібними кроками

Для сервера чи боксу, до якого вже є SSH. Тут нічого не вирішується саме.

```bash
nysh cloud plan <тека> --host <машина>     # без мережі й без витрат
nysh cloud hosts add <ім'я> <user@host[:порт]> --key ~/.ssh/id_ed25519
nysh cloud prepare <ім'я>                  # середовище рушіїв, раз на машину
nysh cloud start <тека> --host <машина> --script cyrillic
nysh cloud state
nysh cloud fetch
nysh cloud verify
nysh cloud stop
```

**Приймач плану:** названо шифру справи. Без неї прогін ляже «нічиїм».

🔴 **Ключ SSH записується шляхом, ніколи не вмістом і не паролем.** Файл машин
лежить у теці простору, яку кладуть у git і в хмарну синхронізацію.

`start` **повертається одразу**: робота живе на машині окремо від з'єднання.
🔴 Після обриву — повторити ту саму команду з тими самими прапорцями (разом із
`--with`): `start` підхопить свою роботу, другої машини не візьме.

⚠ Скільки процесів — вирішує **виміряне** залізо. Машина може показувати 192
ядра там, де ваша частка — 48. `--shards N` приймає лише **менше** фізичного:
більше не сповільнює прогін, а завалює його.

**Велика справа.** Файли понад ~32 МБ їдуть системним `scp` (у рази швидше за
вбудований SFTP); якщо його немає — захід скаже про відкат і поїде повільно.
Десятки гігабайтів — налаштуйте сховище:

```bash
nysh cloud hosts storage <сегмент> --endpoint <адреса>
# ключі — тільки в середовищі: NYSHPORKA_S3_KEY / NYSHPORKA_S3_SECRET
```

🔴 **`fetch` і `verify` — два кроки, і між ними нічого не пропускається.**
`verify` зводить три незалежні знаменники — кадри в теці, число з мети прогону,
тексти на диску — і звіряє **покадрово**. Карантин — не прочитані сторінки.

* **хвіст малий** (до ~2% і до ~сотні сторінок), а машину вже відпущено —
  доганяйте **вдома**: `nysh read <тека>`;
* **бракує багато** — машину ще не гасіть: недороблене лежить на ній.

🔴 **`stop` відмовиться, поки роботу не звірено, — і це правильно.** Кинути
захід свідомо — `--force`; мовчазного шляху туди немає.

## Коли щось пішло не так

| що видно | що це насправді |
|---|---|
| прогін «успішний», а сторінок менше | код повернення повноти не доводить: є клас відмов, за якого лог обривається, перелік збоїв порожній, а процес виходить нулем |
| привезено менше, ніж читалось | звірка **покадрова**: однакове число текстів ще не означає ті самі сторінки |
| «повністю», а на диску не все | карантин переживає перезапуск; `go` на догоні відкладає його вбік і читає хвіст одним процесом |
| пошук по декоду дає нуль без помилки | голоси склались в одну теку й перетерли один одного; вони мусять лежати сестринськими теками `<прогін>-<тег>` |
| машина «не відповідає» одразу після старту | щойно піднятий бокс кілька хвилин не приймає з'єднань — це не привід брати другий |
| заливка йде годинами | немає `scp` у PATH (див. нотатку заходу) або справа на десятки гігабайтів — сховище |
| `go` каже «у теку вже пише інший захід» | та сама справа іншим письмом чи моделлю: два прогони в одну теку перетирають тексти |
| кроп показує не той аркуш | у меті лежав шлях орендованого боксу; забір тепер вписує теку ОРИГІНАЛЬНИХ кадрів, навіть коли їхала стиснута копія |

## Чого тут немає навмисно

**Оренди без стелі.** Кожен захід має бюджет і строк; `--budget` і
`--max-hours` їх лише звужують або розширюють, прибрати не можна.

**Дозволу, який агент дає собі сам.** Стеля автозапуску й `--confirm` — межа
між «дрібна витрата, яку людина дозволила наперед» і «рішення про гроші».

**Другого догону.** Хвіст доганяється один раз. Другий означає, що сторінки не
читаються взагалі, і платити за третю спробу немає за що.
