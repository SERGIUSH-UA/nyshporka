# Як долучитись

## Спершу — ворота проти приватних даних

```bash
uv sync --group dev
pre-commit install          # ОБОВ'ЯЗКОВО, перед першим комітом
```

Пакет виділено з приватного дослідницького репозиторію однієї родини, і головна
небезпека тут — не зловмисник, а випадковість: один `git add -A`, скопійований
для прикладу шматок коду з реальним ідентифікатором особи, шлях із машини
автора в докстрінгу.

```bash
python tools/scan_private.py             # робоче дерево
python tools/scan_private.py --staged    # індекс (стоїть у pre-commit)
python tools/scan_private.py --history   # уся історія, перед КОЖНИМ push
```

Перевірка стоїть **до** коміту, бо git не забуває: файл, доданий і видалений
наступним комітом, лишається в історії назавжди, а прибрати його потім означає
переписати вже опубліковану гілку. Доти, доки гілка не запушена, виправлення
коштує один `filter-branch`; після push — переписування чужих клонів.

🔴 **Виняток — це завжди пара «правило × шлях»**, ніколи «ігнорувати цей файл»
і ніколи не послаблення самого правила. Ворота, які завжди червоні, вимикають —
і тоді вони не ловлять уже нічого.

## Перевірки, які має пройти зміна

```bash
uv run ruff check .
uv run mypy
uv run python -m nyshporka.brand.gen --check
uv run pytest
```

Усі чотири ганяються в CI на Python 3.11/3.12/3.13 і додатково на Windows —
основній платформі аудиторії (зовнішні диски зі сканами, junction'и).

## Що цінується в коді

- **Нуль мусить щось означати.** Джерело, яке не може шукати, не додає нуль до
  суми — воно відмовляється відповідати й каже, чого бракує. Порожній результат
  у генеалогії закриває напрям назавжди, тож «не знайшов» і «не шукав» не
  можуть виглядати однаково.
- **Вимкнена частина вимкнена всюди** — у браузері, в командному рядку, в
  агента. Напівстан («кнопки немає, але команда працює») гірший за відсутність:
  він читається як несправність.
- **Три обличчя, одне ядро.** Браузерна консоль, CLI і MCP — тонкі обгортки
  навколо одного реєстру операцій; логіка живе в `core`, а не в них. Це
  перевіряється тестом (`test_triptych_parity.py`), а не домовленістю.
- **Коментар пояснює ЧОМУ, а не ЩО.** Найцінніші коментарі тут — ті, що
  зберігають вимірювання й ціну помилки («заміряно на 478 прогонах», «показати
  не той аркуш гірше, ніж не показати»). Вони не дають наступному прибрати
  захист, ціни якого не видно з коду.
- **Мова — українська**: коментарі, докстрінги й повідомлення користувачу.
  Інтерфейс браузера двомовний (uk/en), і симетрія перекладу перевіряється
  тестом.

## Тест, який щось доводить

Ворота цього репозиторію писані під конкретні вади, які вже траплялись, і
кожна лишила по собі тест. Якщо ваша зміна торкається:

- **операції** — вона мусить мати вхід хоча б з одного обличчя
  (`test_no_dead_ends.py`);
- **кнопки у фронті** — потрібен обробник, і навпаки, симетрично; плюс ключі
  перекладу в **обох** мовах;
- **поради на кшталт `nysh щось`** — і команда, і кожен згаданий прапорець
  мусять існувати;
- **даних пакета** — файл має бути в git і доїхати **всередині колеса**
  (`test_repo_completeness.py`); правило `data/` у `.gitignore` одного разу вже
  з'їло `archives.yaml`: локально працює, ламається рівно в користувача.

## Нове джерело

Джерело потрапляє в маршрут агента не тоді, коли його зареєстровано, а тоді,
коли воно каже, про що воно. Порядок:

1. **Картка й клас.** Картка `### Канал: \`<id>\`` у
   `docs/agents/where-to-dig-channels.md` і рядок таблиці «Класи каналів» у
   `where-to-dig.md`, що називає цей `id`; копії обох файлів — у
   `.claude/skills/where-to-dig/references/`.
2. **`about = SourceAbout(...)` у класі джерела**: питання, що дає й чого не
   дає, клас дослівно з таблиці, межі (`SourceScope`), на чому шукає збіг і що
   доводить нуль. Невідоме — `None`: воно читається «не задекларовано», а `()`
   — «явно немає».
3. **Справжні `caps`.** Пошук без каталогу кидає `SourceError` із командою, яка
   це лікує, а не повертає `[]`; стеля видачі — `search_ceiling`; на чому шукає
   — `catalog_source()`.
4. **`Hit.repo` — лише через пак** (`repo_for_code`, `resolve_code`);
   `Hit.archive` — як архів пише саме джерело.
5. **Коментар «навіщо»** у `sources/registry.py` поруч із реєстрацією.
6. **Офлайн-тест** `tests/test_sources_<id>.py`, запис у `CHANGELOG.md` і
   зелений `tests/test_source_cards.py`.
