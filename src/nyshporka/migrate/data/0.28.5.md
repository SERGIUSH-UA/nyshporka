# Міграція агента на 0.28.5

## Що змінилось для тебе

**Git знову потрібен для рушіїв читання.** У 0.28.4 PARSeq (`strhub`)
ставився архівом коміту, щоб обійтись без git. Але в parseq підпакети
потрапляють у колесо лише зі списку файлів git, тож з архіву ставився
порожній `strhub`: верхній пакет імпортувався, а `strhub.models.parseq` —
ні, і Писар не вантажився. Теза з 0.28.4 «рушії ставляться без git» хибна.

- Специфікація знову `strhub @ git+https://github.com/baudm/parseq.git@<коміт>`.
- `nysh doctor` і `nysh htr install` перевіряють цілість модулем
  `strhub.models.parseq`: порожній пакет тепер у «бракує: strhub».
- `nysh htr install` такий пакет перевстановлює, а не лишає як є.
- У `install.md` Git — крок 1, перед Нишпоркою. Людині, що ставить усе
  наново, радь саме цей порядок.

## Що сказати людині

«Якщо ви ставили Нишпорку сьогодні вперше (версію 0.28.4), програма читання
могла стати неповною. Я виправлю це однією командою — `nysh htr install`. Git
ставиться першим, ще до Нишпорки.»
