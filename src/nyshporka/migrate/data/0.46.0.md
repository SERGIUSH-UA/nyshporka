## Нові ваги кирилиці

Писар v31 і Дяк-Літописець v15 (реліз `weights-v6`); v29 і v12 — замінені паки, читають
далі. Прочитання старими вагами лишаються чинними; перечитувати не обов'язково.

Писар v29 → v31 (дотрен у два кроки, v30 і v31):

| що міряли | було | стало |
|---|---|---|
| скоропис XVIII ст. (Румянцевський опис, ЦДІАК 57-1-23), CER | 20.7 % | 8.8 % (замір v30; на v31 окремо не переміряно) |
| там само, власні назви | 75 % | 95 % |
| метрики XX ст., 28 небачених рук: звірені прізвища, знайдені в читанні | 65.3 % | 70.3 % |
| метрики XIX ст., те саме | 82.0 % | 81.6 % (приросту немає) |
| сповідні розписи (4 holdout-руки), CER | 11.3 % | 9.6 % |
| звірені оком прізвища (голд-сет, 2 743 згадки) | 56.1 % | 56.7 % (на рівні) |

Дяк-Літописець v12 → v15 (дотрен лише на рядках найвищої певності): рід на аркуші в
голд-сеті (поріг 90) 74.4 → 75.6 %; скоропис XVIII ст. CER 18.3 → 15.2 %; решта на рівні.

## Стор тексту: схема 4 і нові ключі пошуку

- Новий стор — окремий файл `text_store.v4.sqlite`; він збирається з прогонів наново
  командою `nysh text index` (без `--case`). Удвічі менший, збірка йде на всіх ядрах.
- Пошук зводить літери скоропису XVI–XVIII ст.: ꙋ ѹ ѯ ѱ ѿ ѧ ꙗ ѥ ꙃ ѻ ѷ. «Руденко» знаходить
  «Рꙋденко», «Ксенія» — «Ѯенія». ѫ, џ, ꙟ не зводяться.
- Відбиток правил стору (`v4:`) несе таблиці зведення літер: надалі зміну правил звичайний
  `nysh text index` доганяє сам, а `nysh text state` каже, скільки прогонів лишилось.
- Якщо зібрано швидкий індекс (`nysh text state` → поле `fast`), та сама команда доганяє
  і його.

## Що ще змінилось у командах

- `nysh cases cards` читає картки зйомки (Windows OCR) і складає карту меж справ на плівці;
  попередження `fond_not_seen` — плівка, найпевніше, чужа.
- `nysh cases join <тека> --undo [--dry-run]` знімає склейку.
- `nysh read --model <ваги>.safetensors --with <голос>` — голос за PP-основою одним
  проходом; PARSeq-голос за PP-основою — відмова.
- `nysh share pack` відмовляє справі з назвою-заглушкою: назву дає `nysh share card
  <справа> --title "…"`; свідомо віддати як є — `--stub-title-ok "чому"`. `share push
  --ready` таких справ не бере.
- Сховище сторінок приймає ключ року видання `VYD/<код>/<рік>`.
- `nysh note push` і `nysh train from-notes` ріжуть кроп звіреного рядка полігоном рядка;
  читання з певністю `low` лягає в набір міткою `unsure`.
