## Кілька описів — один захід у хмару

`nysh opys read` орендував окрему машину на кожен опис. Кожна оренда несе накладні (старт машини,
моделі) — від кількох центів на рукописі до ~$0.2 на машинописі, хоч би в описі було дві сторінки.
27.11.2026 так вийшло 110 заходів на 429 сторінок за $5.35.

Тепер кілька вже заведених тек читаються одним викликом:

```
nysh opys read <тека1> <тека2> <тека3>
```

Кожна тека проходить свої кроки, а заходи в хмару всіх тек — один `cloud go` на етап: одна черга на
одну машину. Повтор тієї самої команди з тим самим переліком тек забирає результат кожної. Нові теки
заводяться по одній (`nysh opys read <тека> --pdf … --repo … --fond … --opys …`), до зупинки на
метадані; далі — разом.

Захід понад стелю автозапуску не ставиться ні разом, ні по одному: потрібен `--confirm` людини.
