# Міграція агента на 0.24.3

## Що змінилось для тебе

**Будь-яка родина.** Людина просить пошукати не свій рід (замовлення,
сусіди) — заведи родину другим профілем: `nysh profile init <Прізвище>
--name <ключ> --paradigm <парадигма>`, людей родини допиши в `kin`. Пошук
сам упізнає рід за написанням запиту; явно — `--family <ключ>`. Підміняти
рід простору не треба.

**Канал запису.** У метриці й сповідці ім'я дитини, батьки й кума стоять у
різних колонках, і рядковий пошук не бачить запису, де прізвище батька
скалічене. `--record` зводить ознаки родини (прізвище, ім'я, по батькові,
дівоче з `kin`) у межах одного запису. `nysh text find` ганяє його сам; перед
звітом «немає» — `nysh search … --anchors --record`. Формат `kin` і межі
каналу — `references/search-channels.md` скіла `find-surname`.

**Застосунок у Docker.** `nysh serve` у контейнері друкує одне посилання,
`http://127.0.0.1:8788/#pair=…`. Людині досить відкрити його в браузері; якщо в
`-p` інший перший порт — підставити його.
