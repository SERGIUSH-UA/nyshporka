## Спеціалісти

Спеціаліст — модель вузького письма. Зміни для тебе:

- `nysh models get` бере лише бойові ваги. Спеціаліста бери за id або всіх через
  `--specialists`, і лише коли справа цього потребує.
- `nysh models list` друкує спеціалістів окремо: для чого, не для чого, запуск.
- Рушій сам спеціаліста не обирає. Власні файли з іменами `logofet_*`, `regent_*`,
  `pysar_x18_*` у `data/spotter/models` теж лише за явним вибором або записом у
  `PRODUCTION.json`.
- Логофет — окремим голосом (`--with`), не замість Писаря: прізвище в таких книгах
  може стояти лише в російському підписі.

Опис для людини — `docs/specialists.md`.
