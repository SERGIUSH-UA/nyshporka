# Міграція агента на 0.28.4

## Що змінилось для тебе

**Рушії читання не потребують git.** PARSeq (`strhub`) ставиться архівом того
самого коміту, тож `nysh htr install` і крок рушіїв інсталятора працюють на
машині без Git. Раніше людина, що ставила програми в порядку з `install.md`
(Нишпорка, потім Git), бачила «⚠ рушії читання не зібрались», і рушії доставляв
ти. Тепер вони стають з першого разу.

**Зелений рядок «Рушії читання» знову означає, що читання запуститься.** Огляд
середовища питав лише метадані пакетів, тож torch, який стоїть, але не
вантажиться, виглядав готовим. Тепер такий випадок — проблема з причиною:

- «бракує Microsoft Visual C++ Redistributable» — на Windows без цього
  компонента. Ліки — `nysh htr install`: він сам качає офіційний інсталятор
  Microsoft, звіряє підпис і запускає його. Windows покаже вікно дозволу
  адміністратора — попередь людину, що воно з'явиться, і що погодитись треба.
- інша причина — останній рядок відмови `import torch` дослівно.

Рядок «Прискорення (GPU)» у цьому випадку пише «не вантажиться», а не
«torch немає».

## Що сказати людині

«Якщо під час установлення Windows спитає дозволу для Microsoft Visual C++ —
погоджуйтесь: без цього компонента Нишпорка не прочитає рукопис. Git для самої
Нишпорки більше не потрібен; його ставлять для помічника.»
