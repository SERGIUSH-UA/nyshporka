## Опис 0 для фонду без описів

Фонд, у якому описів немає, у шифрі й ключі справи має опис `0`
(`AGAD 301-0-57`), а не `_`. Підкреслення означає лише «опис невідомий».

## Скани AGAD для метричних зеспілів

Посилання на сервер сканів AGAD (`agadd2.home.net.pl` або `agadd.home.net.pl`,
`metrykalia/<зеспіл>/sygn. <N>/indeks.htm`) пакет `nysh share pack` записує
джерелом сканів (`zespol:<зеспіл>:<N>`). Метрика Коронна (`mk:<книга>`) без змін.

## ARCHIUM: адреса переглядача

`nysh get archium https://<хост>/file-viewer/<id>` працює; запису `file:<id>`
більше не потрібно шукати вручну.
