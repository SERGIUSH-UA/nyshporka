# Растр бренду: логотип, фавікон, маскот

Маскот Нишпорки — куниця з лупою й польовою сумкою (див. `brand.yaml`).

Копія готових файлів порталу (`nyshporka-online/app/web/static/img/`), які
збирає з оригіналів бренд-пакета сам репозиторій порталу (скрипт збирання
картинок там же). Застосунок і
консоль роздають їх самі, з пакета, тож без мережі вони на місці.

Руками не правити: оновлювати тут після перезбирання на порталі, копіюючи ті
самі файли.

| файл | де стоїть |
|---|---|
| `logo.webp` | шапка застосунку й консолі |
| `favicon-32.png`, `apple-touch-icon.png` | вкладка браузера, ярлик на телефоні |
| `maskot-vitaie.webp` | домівка порожнього простору: вітання |
| `maskot-lupa.webp` | дашборд; пошук до першого запиту |
| `maskot-mapa.webp` | розбір, коли знахідок ще не передали |
| `maskot-z-doslidnytseiu.webp` | профіль, поки рід не задано |
| `maskot-pratsiuie.webp` | «Роботи», поки щось виконується або чекає в черзі |
| `maskot-kliuch.webp` | сторінка допуску мережевого пристрою |
| `maskot-vyishlo.webp` | «Оновлення»: вийшла нова версія |
| `maskot-onovliuie.webp` | оновлення ставиться |
| `maskot-chekaie.webp` | «Оновлення»: ще не питали; консоль перезапускається |
| `maskot-onovleno.webp` | «Оновлення»: стоїть найновіша |
| `maskot-dzvonyt.webp` | дзвіночок: є сповіщення |
| `maskot-poshta.webp` | дзвіночок: вхідні сповіщення Супряги |

🔴 Маскот показує ПРОЦЕС («вітає», «шукає», «чекає, що дадуть»), а не
ВИСНОВОК пошуку. На видачі пошуку його немає взагалі, і на нульовій теж:
картинка, яка каже «нічого немає», бреше саме там, де хибне «немає» закриває
напрям пошуку назавжди. Правило записане в `brand.yaml`; усі пози перелічені
в `core/view.js` (`MASKOT`), і іншої дороги на екран у них немає.

## Тла (`bg-*.webp`)

Мальовані краєвиди й папір дослідника, 1600 px завширшки.

| файл | де стоїть |
|---|---|
| `bg-papir.webp` | тло сторінок у світлій темі (папір із дубом), під легкою вуаллю |
| `bg-selo.webp` | картина над Оглядом роду (село з церквою в ранковому тумані) |
| `bg-arkhiv.webp` | картина над Оглядом Майстерні (архівна кімната) |
| `bg-hata.webp` | перша зустріч у порожньому просторі (хата під яблунею) |

Решта картин дослідника (дуб над стежкою, дорога до села, річка з вербою,
папір із картою) — для наступних екранів.
